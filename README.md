# Lernfeld 1: Sich im Berufsfeld orientieren

Webseite für Lernende mit den Arbeitsblättern zu Lernfeld 1 (Wirtschaftstheorie und Wirtschaftspraxis, IBA).

- `index.html`: die Webseite (Startseite mit sechs Kacheln: LS 1 bis LS 5 sowie „Präsentieren und Bewerten“)
- `materialien/`: die Arbeitsblätter als Word-Dateien (.docx), die auf der Seite heruntergeladen werden

Neue Arbeitsblätter: Datei in `materialien/` ablegen und in `index.html` in der passenden Lernsituation eine Karte mit Link ergänzen.
